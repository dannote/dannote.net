# Colophon

This site is a collection of static documents, built with [Astral](https://github.com/elixir-volt/astral). [Volt](https://github.com/elixir-volt/volt) handles the browser assets, with [Tailwind CSS](https://tailwindcss.com) for styling.

Pages use ordinary headings, paragraphs, lists, and links. Articles remain readable without JavaScript; Vue adds optional controls to the system diagram.

Type uses the local Helvetica/Arial and monospace stacks. No web fonts are downloaded.

There are no analytics installed.
