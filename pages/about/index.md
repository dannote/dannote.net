# About

I’m Danila Poyarkov, an independent developer. I build open-source tools for coding agents, design automation, and the Elixir ecosystem.

My current work is about giving agents ways to inspect and change real systems: design documents, source code, and running applications. That includes [OpenPencil](https://openpencil.dev), [figma-use](https://github.com/dannote/figma-use), the [Elixir Vibe](https://github.com/elixir-vibe) code-intelligence tools, and [Elixir Volt](https://github.com/elixir-volt).

Earlier work includes SOCKS5 support for nginx, desktop-action support in Xfce’s Garcon library, Russian NLP tools, and Abiko, a search engine for Tor hidden services. I’ve also reported security issues through Google Bug Hunters, Bugcrowd, and CodePen’s bug bounty program.

The [projects page](/projects/) gives a short overview. My [GitHub profile](https://github.com/dannote) has a fuller account, with links to the work. [What I’ve Been Building This Year](/writing/what-ive-been-building-this-year/) explains how the current projects fit together.
