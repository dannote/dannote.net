# About

<img src="/images/danila-poyarkov.jpg" width="460" height="460" alt="Danila Poyarkov" class="not-prose mx-auto mb-6 block size-48 rounded-full object-cover sm:float-right sm:ml-8 sm:mr-0 sm:size-56" />

I’m Danila Poyarkov, an independent developer. My current work spans design editors, code intelligence, JavaScript runtimes, frontend build systems, and recording and replay.

The common thread: design documents should be accessible as structured data, code should be understood through its relationships, and running applications should be inspectable—not just visible in a screenshot.

## Background

Before this current focus, I built software across several ecosystems. In Ruby, that includes exposing PostgreSQL features through ActiveRecord and generating TypeSpec descriptions from serializers. In Elixir, I’ve worked on API specifications, JSON schemas, and Russian NLP tools.

I built [Abiko](https://github.com/abiko-search), a search engine for Tor hidden services, including an Onion v3 implementation and a tor2web proxy. Other systems work includes [SOCKS5 support for nginx](https://github.com/dannote/socks-nginx-module), a [Lua templating engine](https://github.com/dannote/lua-template) adopted by Cloudflare Loom, and [desktop-action support in Xfce’s Garcon library](https://gitlab.xfce.org/xfce/garcon/-/commit/aec77533132eb324180ef771e15226a752573eae).

I’ve also reported security issues through [Google Bug Hunters](https://bughunters.google.com/profile/62602ae8-cf92-4fb0-810c-c9e284f3427e), [Bugcrowd](https://bugcrowd.com/h/dannote), and CodePen’s bug bounty program.
